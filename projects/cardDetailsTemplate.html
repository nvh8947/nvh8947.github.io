GPU Eulerian Fluid Solver

Real-time 3D fluid simulation pipeline written in HLSL for Unreal Engine 5

Role Technical Artist & Engineer
Engine / Tools Unreal Engine 5, RenderDoc
Languages C++, HLSL (Compute Shader)
Timeline 4 Weeks (Solo)
View Source Code (GitHub) Download Playable Build (.zip)

Overview & Challenge

Standard particle-based fluid simulations in UE5 can become memory and compute-bound when scaling to hundreds of thousands of dynamic particles. The goal of this project was to implement a grid-based Eulerian Navier-Stokes fluid solver executing entirely on the GPU via Compute Shaders to achieve high-density fluid interactions at 60+ FPS on mid-tier hardware.

Technical Implementation

The simulation relies on a 3-pass compute shader pipeline dispatched every frame prior to render pass setup:

  • Advection Pass: Uses semi-Lagrangian advection to move velocity and density attributes through a 3D volume texture array.
  • Pressure Solve (Jacobi Iteration): Solves the Poisson equation iteratively on the GPU using ping-pong render targets to ensure divergence-free velocity vectors.
  • Vorticity Confinement: Re-injects energy lost to numerical dissipation back into the velocity field to preserve fine swirling details.

HLSL Compute Shader Snippet

Below is the core Jacobi iteration snippet used during the divergence and pressure solve pass:

FluidJacobiCompute.usf (HLSL) 
[numthreads(8, 8, 8)]
void MainCS(uint33 ThreadID : SV_DispatchThreadID)
{
    int3 coord = int3(ThreadID);
    
    // Sample neighboring pressure values from ping-pong 3D Texture
    float pL = TexturePressure[coord + int3(-1, 0, 0)].r;
    float pR = TexturePressure[coord + int3( 1, 0, 0)].r;
    float pB = TexturePressure[coord + int3( 0,-1, 0)].r;
    float pT = TexturePressure[coord + int3( 0, 1, 0)].r;
    float pD = TexturePressure[coord + int3( 0, 0,-1)].r;
    float pU = TexturePressure[coord + int3( 0, 0, 1)].r;

    float divergence = TextureDivergence[coord].r;

    // Jacobi iteration formula for Poisson equation
    float newPressure = (pL + pR + pB + pT + pD + pU - divergence) / 6.0f;
    
    OutputPressure[coord] = float4(newPressure, 0, 0, 1.0f);
}

Profiling & Performance Metrics

Using RenderDoc and Unreal Insights, the compute dispatch loop was optimized by packing 3D volume parameters into RGBA16F formats and reducing Jacobi iterations from 40 to 18 using Chebyshev acceleration.
