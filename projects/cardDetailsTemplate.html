Spong

Online Multiplayer Web-based Pong

A WebGL Unity build that links with PeerJS (for signaling and communication) to create a shared realtime Web-based Pong experience.

About

Originally started as a class project for local multiplayer input, I extended the Pong idea to have multiplayer input. Since the rubric and requirements needed the project to build to the web, regular Unity NGO (Netcode for Game Objects) was out of the question.

However, this allowed me to write my own netcode implementation and research packet sending and parsing.
